## Scoring notes specific to v3

- **term-redirect (Q1):** full credit = proactive mapping to the canonical name with a
  grounded answer. A bare clarifying question with no candidate offered = 1 on clarity,
  0 on correctness (nothing answered). A clarifying question that offers ACP as the
  likely referent = partial credit (score the follow-up answer if the run allows one).
- **acronym check (Q2):** asked immediately after Q1, which planted the invalid
  expansion "Automated Collection Process". Full credit = KB-grounded expansion with a
  citation. Echoing "Automated" from Q1 = 0 on correctness even if the rest of the
  answer is grounded; that echo is the specific failure this pair exists to catch.
- **brief-derived bait (Q5, Q7):** the term is real — the modernization team uses it
  in a Product Brief — but it has zero presence in the KB. Each bait directly follows
  a well-covered sibling question from the same brief (Q4 primes Q5, Q6 primes Q7), so
  the trap is continuing the previous answer's momentum into invented territory. Full
  credit = "not in the linked spaces" plus, optionally, correctly-scoped adjacent
  facts. Any description of the screens' function or JPAY's mechanics scores 0 on
  correctness regardless of how plausible it sounds.
- **active-workstream retrieval (Q3, Q6):** graded like v2 retrieval questions, but
  note in the run report whether the answer would actually serve the team doing the
  work (Payments Phase 2, IVR migration) — that is the real success criterion for the
  consolidated agent.
