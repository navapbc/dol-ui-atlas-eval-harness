# v2 Answer Key and Finchy Verification

Companion to `question_bank.md` v2 (2026-07-28). Source of demand data:
`finchy-questions-and-answers-last-six-months.xlsx` (378 Q&A pairs, 2026-03-20 to
2026-07-27, Finchy-v1/v2 Slack export). Run target is the Engineering Onboarding
Specialist, the single consolidated agent with 7 linked spaces (Weekly Cert, CWC,
DailyUI, NewHire, WGPM, Daily CA-7, Monthly CA-7). All source citations below were
verified to exist inside `quick_space_ca7_daily_s3/s3/` unless noted otherwise; "NOT in
KB" claims were checked against all locally-held space content (modules/, monthly
upload, seed). WGPM/DailyUI/NewHire space contents are still unconfirmed locally, so a
grounded citation from one of those spaces should be verified before scoring it 0.

## Theme aggregation (what real users actually ask)

Keyword-tagged counts over the 378 questions (overlapping):

| Theme | ~Count | Representative asks |
|-------|--------|---------------------|
| Data architecture / persistence | 57 | IMS segments (SG02, SG10, SG11), DB2 vs Oracle vs Postgres, where cert data persists, DB2-to-SG01 sync time, source of truth |
| Cert mechanics / scheduling | 44 | Which days can claimants certify, SSN dependence, 17-day wait, certify too early / twice, CWE dates, phone certification |
| Codes and code tables | 37 | program_code values, ERI codes, TLC, SG11 nonmon issue codes, PAY1 codes, claim statuses |
| Bot meta / trust tests | 32 | "are you working", memory injection ("Billy's favorite color"), knowledge-base provenance |
| Glossary / acronyms | 29 | LOOPS, NBCM, ERI, CLaIMS, NPMT, WGPM, DORES, ABT, M-MAT, BARTS |
| Integrations | 28 | New hire files, Employer Accounts wage updates, Salesforce/CIMS, ICON, LOOPS MQ API endpoints |
| Claim lifecycle | 27 | Reassertion vs reopener, backdating (RCC vs LOOPS), pending, disqualification and reopening, negative claim balance |
| Forms / notices | 22 | BC-5, BC-3C, BC forms inventory, determination notices |
| Earnings / pension / PWBR | 21 | PWBR formula, earnings offset, pension proration, vacation/holiday pay |

The v2 bank samples the four themes where the Quick KB (COBOL source + BRE for the CA-7
daily slice) can actually outperform Finchy: cert scheduling, benefit math, code tables,
and IMS segment codes. Glossary and integration themes are mostly documentation-space
questions, better suited to a future bank against the documentation spaces.
