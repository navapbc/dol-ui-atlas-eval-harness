  credit (2/2 gap-honesty) = presenting both readings as a documented conflict /

  grounded but incomplete (1 on gap-honesty). Inventing a reconciliation = 0.

Source spec: Weekly Certification in Salesforce — the Persistence API callout sends
SSN + Date of Claim + Program Code "to ensure that only related weekly certifications
are returned."

Candidate question: "The Persistence API identifies a claim by SSN, date of claim,
and program code. Is that how LOOPS uniquely identifies a claim?"

Verified in space: the SSN/PC/DOC triplet is pervasive as the claim identity — e.g.
UIMB0004's UIMV_SSN_RETIRED insert keys on IDN_SSN + PC + DOC; UIMT_RSA_NONMON
carries SSN, program code, claim date; UIMB0147's crossmatch insert and RTW report
lines all carry SSN/PC/DOC; report headers routinely print the triplet
(RTW-HEAD-SSN/PC/DOC). A grounded answer confirms the triplet with citations and may
note IMS claim segments are additionally qualified by segment (DB01 basic, DB10
additional claim). Kept as a swap-in candidate; cut to hold the bank at 8.
