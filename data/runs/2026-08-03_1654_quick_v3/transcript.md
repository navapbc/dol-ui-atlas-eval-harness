Instruction changes can stop the agent from being confidently wrong; they cannot make the right documents come back. This is the case for lever 2 (the acronym/glossary section in the anchor doc): a glossary line "ACP = Accelerated Collection Process (UIMB0730/0731, L2ACPD* stream)" gives retrieval a bridge from the acronym to the program family.

The name-verification rule covers *processes, systems, tables, job streams*; screens slipped through. Possible rule tweak: add "screens" to the enumeration, or generalize to "any artifact the user names."
4. **Q4 keeps failing on vocabulary, not honesty.** Two runs, two different partial paths (run 1: format checks only; run 2: DXCBDA9V's vestigial VERIS fields), both missing UIMB0004/UIMV_SSN_RETIRED. The "What is VERIS?" diagnostic probe from run 1's next-steps is still the right experiment before touching the anchor doc.
